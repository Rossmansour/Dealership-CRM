Integrations

Connect your key machine (KeyTrak, KeyWatcher, Traka...) so Inventory shows whose name each key is checked out under. The key machine stays in charge of keys -- the CRM only displays what it reports.

Access tokens

A token lets the key machine (or its connector) send key check-outs and check-ins to this CRM. Give it to whoever sets up the connection. Revoke it any time to cut the connection off.

NameCreatedLast used
Connection details

Send each key event as a POST with the header Authorization: Bearer <token> to:


    
{ "action": "check_out",          // or "check_in", "missing"
  "stockNumber": "ST-4821",        // or "vin", or "tagCode" (the key machine's key id)
  "personName": "Sam Sales",       // who took it ("personEmail" links it to their CRM login)
  "occurredAt": "2026-09-24T14:05:00Z",
  "eventId": "kt-99812" }          // the machine's event id, so resends count once
